## 开始一个项目

首页默认不选择项目。新建或点击项目后，从左侧 Dock 打开「项目总览」「造价档案」「模型配置」「工作台」「计算台」「附件库」。上方只显示当前页面的子 tab；「计算记录」在工作台内。「更多」保留公用的材料价格库、设置与备份。项目名称可在项目总览中修改；没有模型的项目同样可以填写台账、计算和保存。

收方、签证变更、产值、合同与计算记录分别管理。产值填写时先确认报送对象、金额口径与当期或累计；不同口径的金额不能直接混加。材料价格库用于积累个人报价，带入计算时需核对适用日期、税费口径和来源。

## 表格与导入

### 直接录入与粘贴

点击「添加行」后直接编辑单元格。Tab / Shift+Tab 切换字段；底部「撤销」用于撤回最近的编辑，完成后点击「保存更改」。

从 Excel 复制区域后，点击目标起始单元格再粘贴。区域粘贴会覆盖对应的可见单元格，必要时追加行；校验失败时整次不写入，可在成功粘贴后撤销。粘贴前请核对起始列和当前筛选范围。

### 选区、格式和工作表

拖动单元格选择矩形区域，拖动序号或列标题选择多行、多列；Shift 点击或 Shift 方向键扩展选区。复选框可选择非相邻行。颜色、文字颜色和对齐会应用到当前选区；切换「整列」后设置也会作用于之后新增的行。

「清除格式」清除选区颜色、对齐及条件规则的影响，保留数据。「格式刷」从当前单元格复制颜色与对齐，再拖选目标；Escape 取消。条件格式支持数值或文字条件，可限定选中范围；多条规则按先后顺序应用。导出的 Excel 保留当前显示效果，不转换为 Excel 原生条件规则。

工作台各业务台账可在底部新建、切换和重命名独立工作表，新表沿用字段定义、不复制记录。计算台的电缆、母线槽、支吊架工作表使用同一套操作样式；其余工具按各自规则保存，不支持独立工作表。

### 导入文件

1. 打开「更多 → 导入 Excel」，选择 XLSX、XLS、CSV 或 TSV 文件。
2. 文件包含多张工作表时，先选择目标工作表。
3. 核对预览、表头及字段映射，确认数量、单位、金额和日期对应正确。
4. 确认后追加到当前台账，再核对并保存。文件导入不会直接覆盖已有行。

收方工程量矩阵需先指定楼栋，再按楼层展开；现场收方单文书可整单归档。导入结果仍需核对，不会自行补齐未提供的单位、签认或工程量。原 Excel 文件不会自动存入附件库，需要时另行关联或导入副本。

### 筛选、视图与导出

- 在搜索框输入关键词，或使用「筛选」按列设置条件；支持升序、降序和多列条件组合。
- 「保存当前视图」保留搜索、排序和业务筛选，之后可从已存视图重新打开。
- 格式工具栏中的「字段」可显示、隐藏、重命名及增加字段；自定义字段可删除。隐藏保留内容，内置字段保留业务与公式关联。字段设置即时应用，点「完成」退出，再保存更改。
- 「导出当前筛选结果」导出当前范围；「导出勾选记录」仅导出其中勾选的行。勾选不会改变前一个按钮的导出范围。

文件导出为 XLSX，完成提示中会显示本机保存路径。计算记录的导出包含历史规则、参数、结果及入账时间。

## 计算与历史依据

1. 在「计算台」选择电缆、母线槽、支吊架或其他工具。
2. 填写本表参数和各行的规格、长度等输入；可从 Excel 粘贴输入区域。
3. 打开明细，核对参数来源、公式、单位和中间结果。
4. 需要留存时，确认入账目标项目，再将计算行入账或留存到「计算记录」。

电缆、母线槽、支吊架可在表格底部新建或重命名工作表。各表的数据、默认参数和对齐设置独立；新表沿用当前表的默认参数，不复制计算行。

电缆和母线槽的「基准期铜价」「施工期铜价」直接在列中修改，单位为元/t。勾选任意多行，打开「批量设置」，只勾需要统一修改的参数并应用；其余行和字段保持原值。不同组可分别设置，也可勾选「恢复默认」清除本行例外。五列粘贴顺序为事项、规格、长度、基准期铜价、施工期铜价；原三列粘贴仍可用。

电缆、母线槽、支吊架及自定义规则支持留存计算快照。同一版本不会重复入账；修改参数后再次入账会保留新版本，不覆盖旧记录。在「计算记录」查看明细，或通过「原计算行」返回调整；原行删除后，已保存快照仍保留。

自定义规则支持中文参数、固定值、逐行变量、受限算式和常用数学函数。单位换算、取整、损耗与系数需在规则中明确，不会自动推断。

数量×单价、保温、风管等常用算量在项目工具页保存输入和结果，当前不自动汇入历史计算记录。具体计算口径见 [公式说明](../workbench/FORMULAS.md)。

## 项目助手

1. 点击「AI 助手」打开右侧栏，填写问题或选择常用核对任务。需要更宽阅读区时，点击展开；可切回侧栏。当前应用会话中，切换项目或返回首页保留各项目未发送的问题和范围；重载后不保证恢复。
2. 发送前检查「核对范围」下拉框；旁边问号解释项目、筛选、勾选记录及未保存内容的范围。一般方法咨询可选择不带项目资料。
3. 等待回复，核对来源和依据。记录过多时按界面提示继续发送下一批；后续批次沿用开始时的范围。
4. 有修改建议时先查看原值与建议值，确认后采用。建议进入编辑区，可撤销；最后点击「保存更改」。

助手会话按项目关联。已保存资料与当前未保存快照可能不同，核对时应分清版本。发送的文字、记录和图纸会进入 DSH 会话，并由该会话配置的模型处理。

## 图纸与模型

首次使用前按 [CAD 环境配置](cad-setup.md) 安装 DWG 解析工具。没有图纸时，也可在「模型配置」中手动配置建筑体量。

1. 在项目「模型配置」选择 DWG 图纸，逐张核对单位和标段。
2. 按图层、候选编号或尺寸查找轮廓，用「查看 DWG 局部线条」对照原图。
3. 选择追加到当前模型或建立新模型。不同图纸的放置坐标需人工核对，确认共用坐标系时才沿用同一 CAD 坐标。
4. 填写楼栋号、名称、楼层与层高，核对轮廓后生成模型，再保存更改。

可使用「交给 DSH 初筛」辅助核对；候选摘要和图纸会送入项目会话，结果仍需逐个对照原图确认。天正代理对象、绑定图、缺少高度的二维图纸可能无法可靠解析。

收方和签证变更记录可通过行操作「定位模型」核对位置。部位须能唯一匹配楼栋，楼层有效时高亮对应层；含糊或跨多栋的记录不会自动定位。模型中的记录列表可返回原台账行。

## 附件与原文件

- **引用本机文件**：关联原文件，不复制内容。移动文件或换电脑后，需要重新定位。
- **导入副本**：将文件副本存入工作台数据，可随完整备份保存。
- **关联已有资料**：同一项目中的已有附件可关联到多条业务记录；解除一条关联不等于删除原文件。

预览和引用不修改原图纸或源工作簿。需要随备份迁移的原始资料，应另行保管或导入副本；不要把只在当前电脑有效的引用当作文件备份。

## 备份与同步

### 保存与恢复

「保存更改」将编辑写入 DSH。浏览器草稿只用于恢复未保存输入，不能代替正式保存和备份。

在「备份与设置」点击「导出数据与附件副本」保存完整 JSON 备份。恢复时先导出当前数据，再导入目标备份；确认后进入编辑区，核对并点击「保存更改」才写入 DSH。恢复会替换当前工作台数据，不是追加导入。

### 可选 WebDAV 同步

目前凭据存储仅支持 macOS。在「备份与设置」填写以 `.json` 结尾的 HTTPS WebDAV 文件地址、用户名与应用密码，点击「连接并检查」。密码保存在 macOS 钥匙串。

保存后会尝试上传，打开工作台时检查远端；断网不影响本机保存，恢复连接后可点「立即检查」。首次接入已有远端或发生两端冲突时，先导出备份，再选择保留哪一端。替换前会额外备份另一端，远端不提供强 ETag 时不会自动覆盖已有备份。

同步包含项目、台账、模型参数和附件副本；不包含本机引用的原文件、绝对路径、未保存草稿、模型视角和 DSH 对话。换电脑后需安装兼容版本，并另行复制、重新定位引用文件。

## 容量与使用范围

| 内容 | 当前限制 |
| --- | --- |
| 表格文件导入 | 单文件 20 MB、2 万行、200 列 |
| DWG 上传 | 单文件 25 MB |
| 附件副本 | 单文件 10 MB、单批次总量 20 MB |
| 工作台保存文档 | 45 MB，包含嵌入的附件副本 |

适合个人项目管理。多人同时编辑产生版本冲突时会拒绝覆盖并保留输入，没有自动合并。审批流、完整收付款流水，以及预付款、质保金和罚扣等合同结算规则需要另外核对，不能仅凭付款比例自动推断。
